# REU-Index-for-under-18
This contains an index of Math REUs that accept and don't accept students under the age of 18. Intended for students at FAU High School and similar accelerated dual-enrollment programs. 
Click [here](https://drive.google.com/file/d/1QH6zLnRyKT-nS15rIRWw6raDjCCXZHVy/view?usp=drive_link). 

For the programs that have a "yes", it means that you can apply if you are under 18, and that I have confirmed that this is true with the program directors. If it says no, then it means that either the website indicates that the program doesn't accept students under 18 or I have confirmed with the program directors.
